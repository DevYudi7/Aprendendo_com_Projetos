# Projetos em Python

Este repositório reúne projetos desenvolvidos durante minha jornada de aprendizado em Python.

A ideia é transformar os conhecimentos adquiridos nos estudos em aplicações práticas, explorando desde conceitos fundamentais da linguagem até projetos mais completos.

## O que você encontrará aqui

* Exercícios e desafios de lógica
* Funções e estruturas de dados
* Tratamento de exceções
* Manipulação de arquivos
* Automação de tarefas
* Programação orientada a objetos
* Interfaces gráficas com Tkinter
* Projetos práticos para aplicar os conhecimentos estudados

## Objetivo

Mais do que apenas guardar códigos, este repositório representa minha evolução como desenvolvedor. Cada projeto é uma oportunidade para praticar, testar novas ideias, resolver problemas e melhorar minha forma de programar.

O conteúdo será atualizado conforme novos conhecimentos e projetos forem desenvolvidos.

## Tecnologias

* Python
* Tkinter
* Git e GitHub

> Em constante evolução, um projeto de cada vez.
